## 🚀 Running Locally

```bash
# Install dependencies
npm install --legacy-peer-deps

# Start development server
npm run dev

# Or build for production
npm run build
npm start
```
Open [http://localhost:3000](http://localhost:3000) to view your 3D portfolio!
